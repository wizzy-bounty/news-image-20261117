## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024x1024 PNG, byte-identical on every run, stdlib
only, no network). With Pillow present it draws the page; on the grader's
stock Python without Pillow it copies the pre-rendered `entry.png` bundled
beside it, byte for byte.
